# 轻量 Telegram 会员通知机器人

这是一个极简 Node.js Telegram 机器人，只需要配置 **一个环境变量：`BOT_TOKEN`**，不依赖第三方 npm 包（Node.js 18+ 自带 `fetch`）。

## 功能

- 第一个私聊机器人并发送 `/start` 的用户自动成为管理员，管理员 ID 保存到 `data/state.json`。
- 固定底部菜单：会员套餐、最新通知、联系客服；管理员额外显示「⚙️ 设置」按钮。
- 管理员设置菜单：管理/删除自定义按钮、查看添加按钮格式、开始广播和查看帮助。
- 管理员可以新增/修改/删除自定义底部按钮和自动回复。
- 管理员广播：编写公告 → 二次确认 → 后台发送 → 返回成功/失败统计。
- 用户点击“联系客服”后，发送的文字、图片、文件等消息会转发给管理员。
- 管理员直接回复转发给自己的那条用户消息，即可将回复发回用户。
- 自动保存已启动用户列表，用于广播。

## 管理员命令

- `⚙️ 设置`：打开管理员设置菜单（仅管理员可见）
- `/admin`：管理帮助
- `/buttons`：查看自定义按钮
- `/addbutton 按钮名称|自动回复内容`：新增或修改按钮
- `/delbutton 按钮名称`：删除按钮
- `/broadcast`：开始广播
- `/cancel`：取消当前操作

例如：

```
/addbutton 会员价格|请联系客服了解会员套餐。
```

## 部署

- Build command：`npm install`
- Start command：`npm start`
- 唯一必需环境变量：`BOT_TOKEN`
- 使用 Node.js 18 或更高版本。
- 选择支持常驻后台进程/Worker 的服务，不要选择会自动休眠的静态网站服务。
- 开启平台的 GitHub 自动部署。

## 首次启动特别重要

部署后，先由你本人打开机器人并发送 `/start`。第一个发送 `/start` 的用户会成为管理员；在你完成这一步之前，不要把机器人链接公开给其他人。

## 数据持久化

用户列表、管理员 ID、按钮和客服映射保存在 `data/state.json`。如果免费平台没有持久化磁盘，重启或重新部署可能清空这个文件；请选用有持久化磁盘的服务，或定期备份此文件。

不要把真实 Bot Token 写入代码或提交到 GitHub。若 Token 泄露，请在 @BotFather 立即撤销并重新生成。
