# 轻量 Telegram 会员通知机器人

这是一个极简 Node.js Telegram 机器人，配置 `BOT_TOKEN` 即可运行；可选配置 `ADMIN_ID` 固定管理员，不依赖第三方 npm 包（Node.js 18+ 自带 `fetch`）。

## 功能

- 设置 `ADMIN_ID` 后，指定的 Telegram 数字用户 ID 始终是管理员；未设置时，才由第一个私聊机器人并发送 `/start` 的用户自动成为管理员。
- 固定底部菜单：会员套餐、最新通知、联系客服；管理员额外显示「⚙️ 设置」按钮。
- 管理员设置菜单：管理/删除自定义按钮、查看添加按钮格式、开始广播和查看帮助。
- 管理员可以新增/删除自定义底部按钮，并分别修改按钮名称、链接和回复内容；配置链接后，用户点击底部按钮会收到可打开的链接按钮。
- 管理员广播：编写公告 → 二次确认 → 后台发送 → 返回成功/失败统计。
- 用户点击“联系客服”后，发送的文字、图片、文件等消息会转发给管理员。
- 管理员直接回复转发给自己的那条用户消息，即可将回复发回用户。
- 自动保存已启动用户列表，用于广播。

## 管理员命令

- `⚙️ 设置`：打开管理员设置菜单（仅管理员可见）
- `/admin`：管理帮助
- `/buttons`：查看自定义按钮
- `/addbutton 按钮名称|自动回复内容|链接`：新增或修改按钮（链接可省略）
- `/delbutton 按钮名称`：删除按钮
- `/broadcast`：开始广播
- `/cancel`：取消当前操作

例如：

```
/addbutton 会员价格|请联系客服了解会员套餐。
/addbutton 会员频道|点击下方进入频道|https://t.me/yourchannel
```

在「⚙️ 设置 → 管理自定义按钮」中，也可以分别修改名称、链接和回复内容。链接必须以 `https://` 或 `http://` 开头；发送 `-` 可清除已设置的链接。

## 部署

- Build command：`npm install`
- Start command：`npm start`
- 必需环境变量：`BOT_TOKEN`
- 可选环境变量：`ADMIN_ID`（你的 Telegram 数字用户 ID；设置后优先于 `state.json` 中保存的管理员，并关闭首位 `/start` 用户自动认领管理员的逻辑）
- 使用 Node.js 18 或更高版本。
- 选择支持常驻后台进程/Worker 的服务，不要选择会自动休眠的静态网站服务。
- 开启平台的 GitHub 自动部署。

## 首次启动特别重要

推荐在部署平台的环境变量中填写 `BOT_TOKEN` 和 `ADMIN_ID`。`ADMIN_ID` 填你的 Telegram 数字用户 ID，不能填用户名或机器人用户名。设置后由该 ID 管理机器人，不需要抢先发送 `/start`。如果不设置 `ADMIN_ID`，才会使用第一个发送 `/start` 的用户作为管理员；这种情况下，在你完成首次启动之前不要公开机器人链接。

## 数据持久化

用户列表、管理员 ID、按钮和客服映射保存在 `data/state.json`。如果免费平台没有持久化磁盘，重启或重新部署可能清空这个文件；请选用有持久化磁盘的服务，或定期备份此文件。

不要把真实 Bot Token 写入代码或提交到 GitHub。若 Token 泄露，请在 @BotFather 立即撤销并重新生成。
